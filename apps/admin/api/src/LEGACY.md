# OpenStaff API Legacy Boundary

- `actors` is legacy.
- `jobs` is legacy.
- `auth/service.ts` is legacy.
- `auth/firebase-auth.guard.ts` is legacy.
- The official active model is `User/Profile/Project/PublicPost`.
- No new functionality is added to the legacy layer.
- `Actor/Job` migration is deferred to a later execution step.
