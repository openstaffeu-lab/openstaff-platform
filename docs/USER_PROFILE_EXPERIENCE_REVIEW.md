# User Profile Experience Review

Last updated: 2026-05-22

## Scope

This review captures the first-user experience around identity onboarding, public profile trust, and the transition from draft profile to public-facing profile data.

## Improvements Closed In EXEC-54

- identity onboarding is now grouped into clearer sections
- optional social links are no longer treated like hidden blockers
- RELU AI is visible as an onboarding assistant
- the user can see a public-style preview before leaving the identity step
- category, ESCO, and Uniclass assistance now appears earlier in the flow

## What Feels Better For Users

- less dense first impression
- better required versus optional clarity
- more confidence that information can be edited later
- fewer technical-looking validation failures
- more explanation of public versus private data

## Remaining Product Truth

- only the supported persisted link set is saved into the current production profile contract
- homepage and public-profile approval proof still belongs to the previously closed live visibility baseline
- provider-backed password recovery and Romanian company autofill remain separate EXEC-52 blockers
