# Media-First Experience

OpenStaff entities now treat media as first-class operational context, not decorative attachments.

## Applies To

- professionals
- companies
- projects

## Supported Media

- logo/profile image
- banner/cover preview
- gallery images
- project documents
- video previews
- public card previews

## Operational Requirements

- uploads persist through existing API document/media endpoints
- previews are responsive on mobile
- removal/replacement is exposed in workspaces
- moderation and RELU snapshots retain media/document source context
- public rendering only shows approved, visible entities
