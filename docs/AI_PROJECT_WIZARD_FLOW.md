# AI Project Wizard Flow

The project publish surface now behaves as a four-step RELU-assisted wizard instead of a single long static form.

## Step 1: Upload Media/Documents

- Drag and drop or manual file selection.
- Supports PDF, images, video, DOC/DOCX, XLS-style files, drawings, and other project evidence.
- Image and video previews render before persistence.
- Users explicitly mark which uploads are used for RELU AI analysis.

## Step 2: RELU AI Processing

The workspace records source text and selected document ids for:

- OCR progress
- semantic extraction
- taxonomy extraction
- contract parsing
- predictive summaries

## Step 3: Validation

AI-generated values are advisory and editable. RELU suggestions are marked as AI-sourced and never overwrite user decisions without explicit save/apply action.

## Step 4: Review & Publish

The saved project keeps moderation status, AI interpretation status, selected source documents, preview-ready media, and a confidence path for backoffice review.
