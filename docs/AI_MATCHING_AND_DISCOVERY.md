# AI Matching and Discovery

Project discovery now combines classic filters with RELU-assisted interpretation.

## Smart Match Widget

Public and authenticated project cards show:

- RELU compatibility percentage
- fit label such as Strong Fit or Requires Additional Certifications
- contextual AI confidence
- logged-user-aware scoring in authenticated workspaces

## RELU Flash Predictions

Cards expose compact structured predictions:

- estimated duration
- estimated budget
- main objective
- contract risk
- required certifications

## Conversational Search

Authenticated project discovery includes an AI-style search input. The input maps natural language to:

- geography
- taxonomy
- certifications
- project type
- budget

Traditional status and engagement filters remain available as fallback controls.
