# Public Profile Visibility Baseline

Last updated: 2026-05-20

## Visibility Rules

1. pending content stays hidden from the public surface
2. owners can still see their pending state in dashboard and profile workflows
3. approved content becomes visible in homepage, feeds, profiles, and relevant search surfaces
4. rejected content remains hidden publicly

## EXEC-43 Focus

EXEC-43 keeps the public trust direction from EXEC-42:

- less artificial validation language
- less EXEC/test/demo-looking copy
- more production-safe marketplace framing
